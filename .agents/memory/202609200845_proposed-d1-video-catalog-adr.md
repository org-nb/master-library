# Proposed D1 video catalog ADR

**Date:** 2026-09-20

Added `docs/adr/0001-use-d1-for-video-catalog.md` as a Proposed ADR. It selects
D1 for authoritative editorial and Stream metadata, with private R2 transcript
storage and rebuildable FTS5 and Vectorize search projections.

The ADR does not accept the decision or authorize Worker implementation,
provisioning, data migration, webhook registration, or deployment. The next
implementation step remains platform contract verification.
