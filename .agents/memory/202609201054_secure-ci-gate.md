# Secure CI gate for ADR-0002

Status: implemented for the credential-free validation layer.

Added a least-privilege GitHub Actions workflow at `.github/workflows/ci.yml` by scaffolding Tara's CI template. The workflow keeps permissions read-only by default, pins the checkout and uv setup actions to full SHAs, disables checkout credential persistence, adds timeouts and concurrency cancellation, and runs the repo gate through `uv sync --locked`, `ruff`, `ty`, `pytest`, and `uv audit --preview-features audit-command`.

This does not create delivery or cloud deployment work. It establishes the secure validation gate that must exist before the ADR-0002 dev/prod pipeline and state bootstrap work can be started.
